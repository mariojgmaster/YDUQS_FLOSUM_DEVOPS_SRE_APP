# Checklist — Incidentes confiáveis

- [x] Diferença entre incidente e deployment falho explicitada.
- [x] Fonte de dados de incidente independente do Flosum definida pelo proprietário.
- [x] Proposta de lifecycle e ações de recuperação registrada.
- [x] Modelo de evidências muitos-para-muitos com revisão causal.
- [x] Regra de zero sem cobertura certificada NÃO implicar 0% de falhas.
- [x] Cálculo DORA bloqueado com fontes incompletas/sem proveniência.
- [ ] Papéis e processo de abertura, revisão e certificação homologados.
- [ ] Deployment PROD Flosum inventariado na org.
- [ ] Schema e Permission Sets aprovados.
- [ ] CustomObjects e LWC implementados e testados.
- [ ] Validação/deploy homologados na sandbox (autorização separada).
